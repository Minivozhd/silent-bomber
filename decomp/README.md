# Silent Bomber (SLUS_009.02) — matching decompilation

A work-in-progress matching decompilation of the USA main executable of
*Silent Bomber* (PlayStation, CyberConnect2, 2000). Structure and toolchain
are modeled on the [Parasite Eve 2 decomp project](https://github.com/GabeRealB/parasite-eve-2-decomp).

> **You must own the game.** No game content is committed (`assets/` is
> gitignored). Dump `SLUS_009.02` from your own disc (sha1
> `daf6c9b6771c724928aa8d158f973b181d7b8115`) and place it at
> `decomp/assets/USA/SLUS_009.02`.

## Setup

Requirements (native macOS):

```sh
brew install mipsel-linux-gnu-binutils
python3 -m venv venv && venv/bin/pip install \
    splat64==0.50.0 spimdisasm==1.42.4 rabbitizer==1.16.2 \
    crunch64 intervaltree n64img pygfxd pypng
```

or use the container (Linux toolchain, also the CI path):

```sh
docker build -t silent-bomber-decomp decomp
alias sbmake='docker run --rm -v "$PWD/..":/app -w /app/decomp silent-bomber-decomp make'
```

## Commands

```sh
cd decomp
make split   # regenerate asm/USA/main + linkers/USA from configs/USA/main.yaml
make         # assemble + link + objcopy + sha1 check against the retail EXE
make clean
```

A successful build ends with:

```
build/USA/out/SLUS_009.02: OK
OK: build/USA/out/SLUS_009.02 matches retail SLUS_009.02
```

## Compiler fingerprint

`tools/fingerprint/trial.py` compiles minimal C equivalents of hand-picked
leaf functions from the split asm with gcc 2.6.3 / 2.7.2-cdk / 2.8.1-psx
(all via maspsx) and scores the generated instructions against the original.
Conclusion: **GCC 2.8.1, `-O2 -G8`, ASPSX 2.77** reproduces every trial
function instruction-for-instruction; gcc 2.7.2 differs in register
allocation around `mfhi`, gcc 2.6.3 differs in store scheduling, `-G0`
loses the `%gp_rel` small-data addressing the original uses, and the
original division sequences have no zero-div/overflow traps
(`-mno-check-zero-division`). See `tools/fingerprint/README.md`.

## Layout

```
configs/USA/main.yaml   splat config (canonical; `make split` input)
slus_009.02.yaml        legacy first-pass bootstrap config, kept for reference
slus_009.02.ld          linker script from the legacy bootstrap split
asm/USA/main/           split assembly (regenerated by `make split`)
asm/USA/packages/       DATA.BIN package splits (separate research track)
src/main/               matched C sources (empty so far)
include/                assembler macro scaffolding (macro.inc & friends)
linkers/USA/            splat-generated linker script + undefined symbol lists
tools/                  vendored toolchain (see tools/README.md)
tools/fingerprint/      compiler identification harness
build/USA/              objects, ELF, final binary (gitignored)
```
